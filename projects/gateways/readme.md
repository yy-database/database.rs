# gateways

YYDS **L1 服务模拟** 方言伪装网关目录。线协议像对方，磁盘仍是 YYDS。

| Crate | 伪装 |
|-------|------|
| `yyds-gateway` | 共享内核 |
| `yyds-gateway-mysql` | MySQL |
| `yyds-gateway-pgsql` | PostgreSQL |
| `yyds-gateway-redis` | Redis |
| `yyds-gateway-mongo` | MongoDB |

产品壳只依赖门面 `yyds`。
